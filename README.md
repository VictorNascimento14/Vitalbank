# Vitalbank

Painel de banco digital — visão geral, transações, contas, investimentos, cartões de crédito,
empréstimos, serviços e configurações. Funciona em celular, tablet e computador.

> **v1: só front-end, com dados fictícios.** Nenhuma tela movimenta dinheiro de verdade.

| Papel | Repositório |
|---|---|
| Código (este repositório) | [VictorNascimento14/Vitalbank](https://github.com/VictorNascimento14/Vitalbank) |
| Documentação (cofre Obsidian) | [VictorNascimento14/Obsidian-vitalbank](https://github.com/VictorNascimento14/Obsidian-vitalbank) |

O sistema visual parte do UI kit **BankDash** (Figma Community), traduzido em tokens próprios.

## Rodando

```bash
pnpm install
pnpm dev        # http://localhost:3000
```

Checks: `pnpm lint` · `pnpm type-check` · `pnpm test` · `pnpm build`.

Regras de trabalho neste repositório: [`CLAUDE.md`](CLAUDE.md).
